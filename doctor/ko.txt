; 한국어 DOCTOR —— Weizenbaum の 1966 年 CACM 版 DOCTOR スクリプトの韓国語訳。
;
; 方針: ★日本語版（doctor/ja.txt）を下敷きにする。英語からの逐語訳ではなく、
;       **日本語で一度倒した問題**（主語省略・埋め戻しの助詞・受け皿）を先に引き継ぎ、
;       韓国語で新しく出た問題だけを個別に倒す。英語原文はコメントに残す。
;
; ★韓国語で構造が変わる 6 か所（記録）:
;
;  1. 視点の反転は日本語と同じく**主語を省けば無料**。韓国語も主語を落とすし、
;     ★「당신」は日常会話でむしろ不自然なので、落とすほうが自然な韓国語になる。
;     (저 = 당신) は書くが、入力に「저」が無ければ発火しない。
;
;  2. ★★**조사 が交替する**（은/는・이/가・을/를・과/와・으로/로）。日本語の助詞に
;     無い性質で、放っておくと「저는」と「당신은」が別トークンになり
;     **分解パターンが片方にしか当たらない**。
;     → 入り口（tools/josa.py）で代表形に寄せ、出口（tools/tsunagi_ko.py）で
;       직전の받침を見て実現する。★だからここでは代表形（는・가・를・와・로）だけ書けばよい。
;     ★テンプレート側に `· 를` と書けば、埋め戻された語に合わせて을/를が選ばれる。
;
;  3. ★★**어미 が語幹と融合する**（슬프 + 어요 → 슬퍼요）。日本語の「悲しい／悲しかった」は
;     語幹が残るが、韓国語は表層が変わる。→ ★**キーワードは活用した表層形**にする（슬퍼）。
;     結果として別名が日本語より増える（슬퍼 / 슬프 / 슬픈）。
;
;  4. ★**過去形もキーワードにできない**（했어요・슬펐어요）。英語の (WAS 2 …) は
;     日本語で 3 本 → 1 本になったが、韓国語では**語としては消える**。
;     時間の話は 옛날 / 예전 で受ける。
;
;  5. ★★**受け皿は「요」**。日本語版で最大の発見だった「です」の受け皿
;     （自分について語る文にはほぼ必ず出る・rank 0 なので他が勝てば譲る）が、
;     韓国語では 해요체 の「요」にそのまま対応する。
;     ★語中の「요」（필요・중요）も切れてしまうが、出口で繋ぎ直されるので害は無い。
;
;  6. ★兄弟姉妹の語が**話者の性別で変わる**（형/오빠・누나/언니）。
;     英語 8 語 → 日本語 14 語（年齢で分岐）→ 韓国語 16 語（年齢 × 話者の性別）。
;
; 入力は tools/josa.py で切り、出力は tools/tsunagi_ko.py で繋ぐ。
;
