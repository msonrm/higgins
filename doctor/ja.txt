; ★★★**知っているが、私の話ではない語**（2026-09-03）
;
; ★日本語には空白が無いので、分かち書き（tools/wakachi.py）は
;   **スクリプトのキーワードを辞書にして最長一致**で切る。すると
;   ★**短いキーワードが長い語の中から出てくる** ―― 「大丈**夫**」から `夫`、
;   「**しかも**」から `かも`、「部屋に**はい**って」から `はい`。
;   出てきてしまえば ELIZA には見分けようが無いので、**家族の話や肯定の話が
;   まるで無関係な文に返る**（実測。下の表の「食われる語」がその実例）。
;
; ★★**直し方は「長いほうを宣言する」**。辞書は**照合に使う語**から作られる
;   （`collect_vocab`）ので、ここに書けば最長一致がそちらを採り、短いキーワードは
;   もう切り出されない。★中身は `(NEWKEY)` ＝ **「私のキーワードではない、次を探せ」**
;   ―― 原典が `REMEMBER` / `WAS` / `LIKE` で使っているのと同じ道具。
; ★★**NEWKEY なので、たまたま一致しても害が無い**（次の候補へ落ちるだけ）。
;   だから安心して足せる ―― これが「無害に増やせる宣言」であることが要点。
;
;   | 守る対象 | 食われていた語 |
;   |---|---|
;   | `夫`（家族） | 大丈夫 / 工夫 / 水夫 |
;   | `かも`（たぶん） | しかも |
;   | `似`（似ている） | 似顔絵 / 似合 |
;   | `はい`（肯定） | はいる / はいって / はいり |
;   | `いつ`（疑問） | いつか |
;   | `何`（疑問）・`もし`（if） | 何も（「何もしたくない」から `もし` まで出ていた） |
;   | `いや`（否定） | いやな / いやだ / いやで（＝不快の「嫌」） |

(工夫 ((0) (NEWKEY)))
(水夫 ((0) (NEWKEY)))
(しかも ((0) (NEWKEY)))
(似顔絵 ((0) (NEWKEY)))
(似合 ((0) (NEWKEY)))

(はいっ ((0) (NEWKEY)))

;
; ★`から` は **理由**（疲れている**から**）と**起点**（学校**から**帰った）の二役。
