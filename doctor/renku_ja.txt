;
; 連句 —— 自由律俳句の付合。DOCTOR ではない ELIZA スクリプト。
;
; ★ELIZA は「プログラム」で DOCTOR は「その上に載せた script の一例」。
;   Weizenbaum の設計思想（script を差し替えれば人格が変わる）を額面どおりに使う。
;
; ★設計の要点:
;  1. **助詞をキーワードにする** —— 「が」「を」「に」の前は名詞句なので、
;     スロット 1 に**句の素材**が入る。wakachi は辞書外を 1 塊で残すので、
;     ユーザー固有の語（カキフライ等）がそのまま拾える。
;  2. ★**外しが技法**。連句は「つきすぎ」も「はなれすぎ」も嫌う ——
;     「意味は通じないが無関係でもない」が正解の領域として定義されている。
;     ELIZA の「内容を理解しない」という限界が、ここでは作法になる。
;  3. ★★**MEMORY が主役**。DOCTOR では間が持たないときの埋め草だったが、
;     連句では「そういえば」と**遠い話題を持ってくる**技法そのもの。
;
; 試す: python3 tools/talk.py doctor/renku_ja.txt
;

(なにか 一句)

(が
    ((0 が 0)
        (1 の あたりで 靴紐が ほどける)
        (1 は もう 誰も 使っていない)
        (1 を 思い出す 帰り道)
        (1 に ついて 誰にも 話していない)
        (1 の 話 を している うちに 日が暮れた)))

(を
    ((0 を 0)
        (1 の 隣に 座って いいですか)
        (1 だけが 残った)
        (1 を 数えている 人がいる)
        (誰も 1 の 話を していない 昼下がり)))

(に
    ((0 に 0)
        (1 まで 歩いて 行けそうな 気がした)
        (1 で 待って いたのに)
        (1 の ことは 誰も 覚えていない)
        (1 へ 続く 道が 工事中)))

(は
    ((0 は 0)
        (1 と 言われても 冷蔵庫は 開けたまま)
        (1 の 写真 だけ 残っている)
        (1 について 考える 信号待ち)
        (1 は 三日 続いた)))

; ★MEMORY = 「そういえば」「それで思い出したんだけど」。
;   4 回に 1 回、遠い話題を持ってくる。
(MEMORY が
    (0 が 0 = そういえば 1 の こと)
    (0 が 0 = 1 は どうなった のだろう)
    (0 が 0 = 1 の 話 だった)
    (0 が 0 = 1 が あった 日 の こと))

; ★何も拾えないとき。引用を持たない純粋な外し。
(NONE
    ((0)
        (傘立てに 誰の傘も ない)
        (自転車が 倒れたまま 夕方)
        (レシートだけが 増えていく)
        (コンビニの 前で 立ち止まる 理由がない)
        (エレベーターに 一人 だけ 乗っている)
        (定食屋の テレビが ついている)))
