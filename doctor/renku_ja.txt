;
; 連句 —— 自由律俳句の付合。DOCTOR ではない ELIZA スクリプト。
;
; ★ELIZA は「プログラム」で DOCTOR は「その上に載せた script の一例」。
;   Weizenbaum の設計思想（script を差し替えれば人格が変わる）を額面どおりに使う。
;
; ★設計の要点:
;  1. **助詞をキーワードにする** —— 「が」「を」「に」の前は名詞句なので、
;     スロット 1 に**句の素材**が入る。wakachi は辞書外を 1 塊で残すので、
;     ユーザー固有の語（カキフライ等）がそのまま拾える。
;  2. ★**外しが技法**。連句は「つきすぎ」も「はなれすぎ」も嫌う ——
;     「意味は通じないが無関係でもない」が正解の領域として定義されている。
;     ELIZA の「内容を理解しない」という限界が、ここでは作法になる。
;  3. ★★**MEMORY が主役**。DOCTOR では間が持たないときの埋め草だったが、
;     連句では「そういえば」と**遠い話題を持ってくる**技法そのもの。
;  4. ★★★**本歌取りは試して外した**（2026-08-29・実機判定）。
;     「型を残して語を差し替える」は ELIZA の分解 → 再構成そのもので、機構としては
;     完璧に嵌まった。だが実際に打つと ★**有名句が出た瞬間に熱量が冷める**。
;     ★連句の面白さは「この機械が今つくった」という感覚に依存していて、
;     既製の名句を持ち出すと**手の内が見えて驚きが消える**。
;     ★★加えて本歌取りは**作者性を要求する技法** —— 人間がやれば教養と機知の表明だが、
;     機械がやると「データベースを引いただけ」になる。
;     ★**機構が嵌まることと、効くことは別**。実装は git 履歴（67bb643）に残っている。
;
;  5. ★★**季と連想**（2026-08-29 追加）。実機で「相合傘もレンタル可能らしいよ」に
;     NONE の句「傘立てに誰の傘もない」が返り、**偶然だったのに連想したように見えた**。
;     ★**連想の実装 = 語ごとに跳び先の情景を持つこと**。それを季節・天気・時間の語で
;     やれば**そのまま連句の季**になる（要望 2 件が同じ実装で満たせた）。
;     ★助詞は rank 0 なので、季語に rank 3 を与えて優先させる。
;     引用のある句と無い句を混ぜる —— 引用があると「拾われた」感が出て、
;     無いと「跳んだ」感が出る。
;
;  6. 効いた型の共通点（実機のやりとりから）: **具体的な場所・物・動作** /
;     **過去形・断念・不在** / **日常の断片** / **オチが無い**。
;     ★助詞の乱れ（「終電をしても一人」）は**味として許容**という判定も出ている。
;
;  7. ★★★**機械の持ち分は短くする**（2026-08-29・実機判定）。
;     「前に見たような形を見た途端に機械生成らしさを感じてだめ。
;      **『隣に座っていいですか』は強すぎる。長いフレーズはユーザーは覚えちゃいがち**」。
;     ★**固定部分が長いほど記憶され、再出したときに有限性が露呈する**。
;     ★★しかも**良い句ほど覚えられる**ので、質を上げると再出時の失望が大きくなる。
;     ★★★対処 = **固定部分を短く / 数を多く / 個性的すぎる句は持たない**。
;     句全体の長さは入力（スロット 1）が担うので、**入力が主役で機械は脇役**の配分にする。
;     ※ 本歌取りが冷めたのと同じ構造（「見たことがある」で錯覚が壊れる）。
;
; 試す: python3 tools/talk.py doctor/renku_ja.txt
;
