;
; हिन्दी DOCTOR —— Weizenbaum の 1966 年 CACM 版 DOCTOR スクリプトのヒンディー語訳。
;
; 方針: ★日本語版（doctor/ja.txt）と韓国語版（doctor/ko.txt）を下敷きにする。
;       英語からの逐語訳ではなく、**先に倒した問題を引き継ぎ**、ヒンディー語で
;       新しく出た問題だけを個別に倒す。英語原文はコメントに残す。
;
; ★ヒンディー語で構造が変わる 6 か所（記録）:
;
;  1. ★★**受け皿がそのまま使える。** 日本語「です」・韓国語「요」は、英語の受け皿
;     キーワード `I`（自分の話を全部拾う）が**主語省略で消える**ことへの対処だった。
;     ★ヒンディー語は主語を落とさないので、**`मैं` が英語の `I` と同じ働きをする**。
;     ★ただし**与格主語構文が非常に多い**（「मुझे डर लगता है」＝私は怖い）ので
;       `मुझे` にも受け皿を置き、主語が落ちた文のために `हूँ` を rank 0 で置く。3 枚重ね。
;
;  2. ★★**動詞が主語に一致する。** ここが日本語・韓国語に無い費用。視点の反転は
;     「単語の置換」で書けるが、閉じたクラス（代名詞・所有形・繋辞）だけでは足りず
;     **-ता → -ते**（主格 1 人称 → आप）まで要る。
;     ★★これは**開いたクラスに対する閉じた表**なので、原理的に取りこぼす。
;     ★フランス語版（Musée du Jeu de Paume・CNRS 校訂）も**同じ問題を解かずに
;       受け入れている** —— `(JE = VOUS)` はあるが `(VEUX = VOULEZ)` は無い。
;       だから「この訳の手抜き」ではなく、**DOCTOR を一致のある言語へ移すときの共通の費用**。
;     ★**与格主語構文は無料**（「मुझे डर लगता है」→「आपको डर लगता है」で
;       लगता は डर に一致しているので動かない）。危ないのは**主格主語の -ता だけ**。
;     ★★**ただし「無条件の置換」ではいけない。** ELIZA の置換は語ごとに無条件なので、
;       3 人称の文まで書き換わる（「मेरा दोस्त बात करता है」→「… करते है」）。
;       → **PRE で条件付きにする**（下の -ता → -ते の節）。★英語原典が
;         `(YOU'RE = I'M … (PRE …))` で使っているのと同じ手で、**エンジンは無改造**。
;     ★★**フランス語版はこれをやっていない**（`(JE = VOUS)` はあるが動詞は素通り）——
;       つまり「一致のある言語では解けない」のではなく、**ELIZA の語彙の中に答えがある**。
;     ★残る限界は**網羅**だけ（表に無い動詞は反映されない）。壊れはしない。
;       ★逆向き（आप → मैं の -ते → -ता）は未実装。
;
;  3. ★★**機械に性別が生じる。** ヒンディー語は 1 人称の動詞が話者の性で変わる
;     （मैं समझता हूँ / मैं समझती हूँ）。★日本語・英語・韓国語では**起きない問題**。
;     ★★**男性に決め打つ**（msonrm さんの判断・2026-09-03）—— 1966 年の DOCTOR は
;       Rogers 流の精神科医のパロディで、当時のイメージは男性。ヒンディー語の
;       無標も男性形。★**避ける方針は一度採って失敗した** —— 与格・非人称で
;       書けば性別は出ないが、**方針を書いただけで検査を付けなかったので
;       2 か所（`सकता` / `करता`）で静かに漏れていた**。決めたら検査を付けること。
;     ★検査 = `tools/check_hi_gender.py`（**`मैं` の後ろに来る動詞が女性形なら失敗**）。
;       ★女性形そのものを禁じてはいけない —— 「क्या यह याद बार-बार आती है」の
;       `आती` は**女性名詞 याद に一致している**のであって話者の性ではない。
;     ★**相手（ユーザー）の性は分からない**ので、そちらは引き続き避ける
;       （「आप उदास हैं」のように不変化の語で書く）。
;
;  4. ★★**引用は「文の最後」にしか置けない。** ヒンディー語も SOV なので、
;     日本語と**同じ制約**を受ける —— 引用した節を文の途中に埋めると、その節の
;     定動詞が地の文の途中に居座って読めなくなる（実測:「आप आपकी नौकरी अच्छी
;     नहीं है क्यों कहते हैं」）。日本語版は「 」で囲んで凌いだが、ヒンディー語には
;     補文標識 **कि** があるので、**末尾に置けば囲まずに済む**
;     （「आप यह क्यों कहते हैं कि 1 2 3」）。フランス語の `VOUS DITES QUE 1` と同じ形。
;     ★★裏返すと**裸の断片引用（英語の `(YOUR 3)`）は使えない** —— 頭から切り出すと
;       主語がスロット 1 に取り残される（実測「आपकी मदद कर सकते हैं」）。
;     ★おまけに**打てない字を印字しない**という性質が保たれる ——
;       デーヴァナーガリーの席で打てる記号は 空白 / `।` / `॥` だけ。
;     ★**もう一つ効く型**: 分解の**スロット 1（見出し語の前）をそのまま頭に置く**。
;       SOV では左文脈が丸ごと well-formed なので、「1 याद अभी क्यों आई」のように
;       前を引用して続けられる。★英語では使えない型（SVO は左に主語しか無い）。
;
;  5. ★**後置詞は分離語**なので、韓国語の 조사 のような剥がしが要らない。
;     テンプレート側に को・से・का をそのまま書いてよい。
;     ★ただし **का/की/के は後続の名詞の性数に一致する**ので、埋め戻しの後ろに置くと
;       形を選べない。→ 一致を要求しない言い回しにしてある。
;
;  6. ★**家族語は性で分かれるが年齢では分かれない**（韓国語と逆）。
;     英語 8 → 日本語 14 → 韓国語 16 → ヒンディー語 16。
;
; ★DLIST を持つ語に置換を付けるときは、**置換後の形にも同じタグを付ける** ——
;   タグは語に付いているので、置換で語が変わるとタグごと消える（実測で踏む形）。
;
; 入口は tools/hindi_in.py（danda を切る・nukta を分解形に寄せる）、
; 出口は tools/tsunagi_hi.py（句読点の前の空白を落とす）。
;

;(YOU = I ((0 I REMIND YOU OF 0) (=DIT)) ((0 I ARE 0) ... ((0 I 0 YOU) ... ((0 I 0) ...
(आप = मैं
    ((0 मैं 0 याद 0)
        (=समान))
    ((0 मैं 0 हैं 0)
        (आपको क्यों लगता है कि मैं 3 हूँ)
        (क्या यह मानकर अच्छा लगता है कि मैं 3 हूँ)
        (क्या कभी आप ख़ुद 3 होना चाहते हैं)
        (शायद आप 3 होना चाहते हैं))
    ; ★★英語の (0 I 0 YOU) —— **相手の動詞をそのまま引用して返す**型
    ;   （WHY DO YOU THINK I 3 YOU）。★一度は諦めた（-ते 形のまま मैं の文へ入れると
    ;   人称がずれる）が、**逆向きの前変換（-ते → -ता）を足して取り戻した** ——
    ;   ここへ来る時点で動詞は मैं に一致した形になっている。
    ((0 मैं आपको 0)
        (आपको क्यों लगता है कि मैं आपको 4)
        (आपको यह मानना अच्छा लगता है, है ना)
        (सच में, मैं आपको 4)
        (क्या किसी और को भी ऐसा लगता है))
    ((0 मैं 0)
        (बात आपकी हो रही थी, मेरी नहीं)
        (मेरे बारे में आप क्या सोचते हैं)
        (असल में बात मेरी नहीं है, है ना)
        (अभी आपको कैसा लग रहा है))
    ((0)
        (मेरे बारे में आप क्या सोचते हैं)))
(आपने = मैंने (=आप))
(आपको = मुझे (=आप))
(आपसे = मुझसे)

;(MY = YOUR 2 ((0 YOUR 0 (/FAMILY) 0) ... ((0 YOUR 0) ...
(मेरा = आपका 2
    ((0 (* आपका आपकी आपके) 0 (/परिवार) 0)
        (अपने परिवार के बारे में और बताइए)
        (घर में और कौन-कौन है)
        (2 4)
        (माँ या पिता के बारे में सोचने से और क्या मन में आता है))
    ; ★スロット 1（見出し語の**前**）も付ける —— SOV では左に主語が来るので、
    ;   落とすと引用から主語が消える（実測「कि आपकी मदद क्यों नहीं करते」）。

    ;   `कि` の後ろ（＝文末）に置くしかなく、頭から切り出した断片は主語を失う
    ;   （実測「आपकी मदद कर सकते हैं」＝ 主語の मैं がスロット 1 に取り残される）。
    ((0 (* आपका आपकी आपके) 0)

        (तो बात यह है कि 1 2 3)
        (और क्या आपको अपना लगता है)
        (यानी यह आपके लिए मायने रखता है))
    ((0)
        (यानी यह आपके लिए मायने रखता है)))
