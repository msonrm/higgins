# Higgins

**Weizenbaum の ELIZA（1966）と日本語で話す。キーボードは要らない。**
**Select で相手を替えられます —— 日本語 → 1966 年の原典（英語）→ 韓国語 →
ヒンディー語。**

1966 年の DOCTOR スクリプトが、そのまま答えます。エンジンは Anthony Hay による
忠実な C++ 再実装（CC0）で、**1 行も変えていません** —— 足したのは日本語の入口と
出口（分かち書きと、空白を繋ぐ処理）だけです。

日本語はゲームパッドだけで打ちます。左手で子音の行を押さえ、右手で母音を叩くと
かなが出る。左スティックで漢字に変換する。**キーボードもシステム IME も要りません。**

名前は『マイ・フェア・レディ』のヒギンズ教授から。言葉づかいを教える人の名前です。

## 打ち方

### かな —— 左手と右手の同時押し

左手（十字キー ＋ L1）で**行**、右手（フェイスボタン ＋ R1）で**段**を選び、
**同時に押す**と 1 字入ります。

| 左手 \ 右手 | R1 | 左のボタン | 上のボタン | 右のボタン | 下のボタン |
|---|---|---|---|---|---|
| （なし） | あ | い | う | え | お |
| ← | か | き | く | け | こ |
| ↑ | さ | し | す | せ | そ |
| → | た | ち | つ | て | と |
| ↓ | な | に | ぬ | ね | の |
| L1 | は | ひ | ふ | へ | ほ |
| L1 + ← | ま | み | む | め | も |
| L1 + ↑ | や | 「 | ゆ | 」 | よ |
| L1 + → | ら | り | る | れ | ろ |
| L1 + ↓ | わ | ゐ | ？ | ゑ | を |

| そのほか | |
|---|---|
| R2 | ん（続けて押すと を → んを → ん と回ります） |
| L2 ＋ R2 | っ |
| L2 を単押し | 直前の字を小さく（ゃゅょ など） |
| 右スティック ↑ | 濁点・半濁点 |
| 右スティック ← | 1 字消す |
| 右スティック → | 長音「ー」 |
| 右スティック ↓ | 「、」→ もう一度で「。」→ もう一度で全角空白（続けて倒したときだけ差し替わります） |

### 漢字にする —— 左スティック

| 操作 | 何が起きるか |
|---|---|
| 左スティック ↓ | 変換する／次の候補 |
| 左スティック ↑ | 前の候補。**いちばん上でさらに押すと ひらがな → カタカナ**が現れます |
| 左スティック ←→ | 文節を移る |
| **R2 ＋ 左スティック ←→** | **文節の長さを変える** |
| 左スティック押し込み | **1 回目は確定**（下線が外れる）。**もう一度押すと ELIZA へ渡します** |
| 右スティック押し込み | 変換をやめる（もう一度で**まだ確定していないかな**を捨てる）。★確定した字は消えません —— 消すときは右スティック ← |
| 右スティック ← | 変換をやめて、打ったかなに戻す |

候補は 5 つずつ出て、窓の下の点がページを示します。いちばん下の候補からさらに ↓ を
押すと先頭に戻ります。変換中にそのまま次の字を打ち始めても構いません —— そのときの
選択で確定して、続きが打てます。

**下線が引かれている字が、まだ確定していないところ**です。左スティックの押し込みで
下線が外れ、もう一度押すと ELIZA に渡ります。

### 打っていないとき

| 操作 | 何が起きるか |
|---|---|
| 左スティック ←→ | カーソルを動かす |
| 左スティック ↑↓ | 行が複数あるなら**行を移る**。1 行なら前の話を遡る |

欄は 1 行から始まり、長く打つと 3 行まで伸びて、そこから先は流れます。

| Select | **相手を替える**（日本語 → 英語 → 韓国語 → ヒンディー語 → 日本語）。欄が空のときだけ |
|---|---|
| Start | メニュー（つづける / やめる） |

変換の癖は使うほど手に馴染みます（学習はポートのフォルダに残るので、SD カードごと
持ち運べます）。

## 英語で話す —— Select

Select を押すと、**1966 年 CACM の原典 DOCTOR**（英語）に相手が替わります。
替わると相手が挨拶するので、それが目印です。**欄が空のときだけ**切り替わります
（送っていない文が残っていると、それが誰宛てなのか決まらないため）。

4 つの相手は**記憶も規則も別**です。会話は 4 本並んで進みます。

打ち方は T9 —— 左手（十字キー ＋ L1）で行、右手（フェイスボタン ＋ R1）で列。

| 左手 \ 右手 | R1 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| （なし） | 1 | ( | ? | ) | ! |
| ← | 2 | a | b | c | |
| ↑ | 3 | d | e | f | |
| → | 4 | g | h | i | |
| ↓ | 5 | j | k | l | |
| L1 | 6 | m | n | o | |
| L1 + ← | 7 | p | q | r | s |
| L1 + ↑ | 8 | t | u | v | |
| L1 + → | 9 | w | x | y | z |
| L1 + ↓ | 0 | @ | # | - | _ |

| そのほか | |
|---|---|
| L2 を単押し | **押すたびに 一時 → 続く → 解除 と回ります**（下の表） |
| L2 を長押し（0.4 秒） | 大文字固定。もう一度長押し、または単押しで解除 |
| R2 | 数字の 0 |
| 右スティック ← | 1 字消す |
| 右スティック ↑ | アポストロフィ `'` |
| 右スティック → | スラッシュ `/` |
| 右スティック ↓ | 空白 → もう一度で `.` → もう一度で `,` |
| 左スティック押し込み | 送る（英語には変換が無いので **1 回**） |

★**空白は右スティック ↓** です。ELIZA は空白で語を切るので、これが無いと 1 語しか
送れません。

### 右下の箱

英語では、いま押している**行のフェイスボタン 4 つぶん**が出ます（`abc` / `pqrs` /
`@#-_`）。どのボタンに何があるかを見ながら打てます。
（日本語は「あ」など、その行の代表の字です。）

箱の**左（枠の外）**にシフトの印が付きます。**L2 を単押しするたびに回ります。**

| 印 | 意味 | 次に単押しすると |
|---|---|---|
| （なし） | 小文字 | ⇧ |
| ⇧ | 次の 1 字だけ大文字 | △ |
| △ | 大文字が続く（空白・記号でも解ける） | （なし） |
| ▲ | 大文字固定（L2 長押しで入る） | （なし） |

★**どの状態からも単押しだけで抜けられます。** スマートフォンのシフトキーと同じ回り方です。

箱の中の字も大文字になるので、**打つ前に大文字かどうかが分かります**。

★配置は GIME（同作者のゲームパッド多言語入力）の英語モードと同じです。

## 韓国語で話す —— Select を 2 回

もう一度 Select を押すと、**韓国語の DOCTOR** に替わります。日本語版を下敷きに
訳したもので、ハングルは**変換が要りません**（打った字がそのまま確定します）。

### ハングルの組み立て

左手（十字キー ＋ L1）で**子音の行**、右手（フェイスボタン）で**母音**。
同時に押すと 1 音節できます。

| 左手 | 何も押さない | ← | ↑ | → | ↓ |
|---|---|---|---|---|---|
| **そのまま** | ㅇ | ㄱ | ㄴ | ㄷ | ㄹ |
| **L1 と一緒** | ㅁ | ㅂ | ㅅ | ㅈ | ㅎ |

| 右手 | R1 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| **そのまま** | ㅡ | ㅓ | ㅗ | ㅏ | ㅜ |
| **R2 を押しながら** | ㅣ | ㅕ | ㅛ | ㅑ | ㅠ |

★**R2 は母音より先に押さえてください。** 同時に押すと、離したときに ㅣ が足されて
`녀` が `녜` になります。

### 받침（パッチム）

**母音を押さずに十字キーだけ**を押すと、いま組んでいる音節の下に付きます。
もう一度別の子音を足すと**겹받침**（ㄳ ㄵ ㄶ …）になります。

- **L2** = ㅇ받침（「何も押さない」行は十字キーでは押せないので）
- ★**押したまま行を変えると付け替わります**（押し間違いの直し）
- ★**間違えて받침になっても、そのまま母音を押せば元に戻ります** ——
  次の音節の頭を先に押してしまったときは、母音が来た時点で「あれは頭だった」と
  判断して戻します

### その他

| 操作 | 何が起きるか |
|---|---|
| 右スティック ↑ | **濃く・激しく**する（평음 → 격음 → 경음）。받침が付いていれば받침のほうが替わります |
| 右スティック → | **複合母音**（ㅗ → ㅘ / ㅜ → ㅝ） |
| 右スティック ↓ | 空白 → `.` → `?` → `,` → `'`（続けて押すと回ります） |
| 右スティック ← | 1 字消す |
| 左スティック押し込み | 送る（変換が無いので **1 回**） |

★**空白は右スティック ↓** です。韓国語も分かち書きするので、これが無いと
ELIZA が語を切れません。

右下の箱には、いま押している**行の子音**（ㅇ ㄱ ㄴ …）が出ます。

## ヒンディー語で話す —— Select を 3 回

もう一度 Select を押すと、**ヒンディー語の DOCTOR** に替わります。日本語版を
下敷きに訳したもので、デーヴァナーガリーも**変換は要りません**（打った字が
そのまま確定します）。

打ち方は**かな・ハングルとは骨組みが違います**。デーヴァナーガリーの子音は
5 つの組（varga）× 組の中の 5 段で並ぶので、**左スティックで組を選び、
十字キーで段を選ぶ**という 2 段構えになります。

### 子音 —— 左スティックで組、十字キーで段

★**左スティックは「倒しっぱなし」ではなく、倒すたびに切り替わります**（latch）。
左の親指で十字キーとスティックを同時に扱えないための作り。同じ向きへもう一度
倒すと中立に戻ります。**いま選んでいる組は右下の箱に出ます。**

| 左スティック | 十字 ↑ | 十字 → | 十字 ↓ | 十字 ← | L1 |
|---|---|---|---|---|---|
| **（倒さない）** | प | फ | ब | भ | म |
| ↑ | क | ख | ग | घ | ङ |
| → | च | छ | ज | झ | ञ |
| ↓ | ट | ठ | ड | ढ | ण |
| ← | त | थ | द | ध | न |

★**倒さない状態が प の組**なのは、いちばんよく使う組を「何もしない」に置くため。

### そのほかの子音 —— L3 で 1 つだけ

左スティックを**押し込む**と、次の 1 子音だけ別の層になります（打つと自動で戻ります）。

| | 十字 ↑ | 十字 → | 十字 ↓ | 十字 ← |
|---|---|---|---|---|
| **L3 のあと** | य | र | ल | व |
| **L3 のあと + L2** | श | ष | स | ह |

### 母音 —— フェイスボタン

子音のあとに押すと **matra**（母音記号）になり、子音が無ければ**独立母音**が出ます。
どちらになるかは自動です。★子音だけを打つと **a の音を背負ったまま**になります
（`क` は「ka」）。

| ボタン | 上 △ | 右 ○ | 下 ✕ | 左 □ | R1 |
|---|---|---|---|---|---|
| **独立母音** | अ | इ | उ | ए | ओ |
| **matra** | ा | ि | ु | े | ो |

| | |
|---|---|
| L2 ＋ ✕ | ऋ / ृ |
| L2 ＋ R1 | nukta `़`（क → क़） |

### 結合子音（conjunct）と修飾

★**子音を続けて打っても勝手にはくっつきません**（`नम` は न と म の 2 字）。
くっつけたいときは **R2 を単独で叩いて halant を打ちます** —— `क` → R2 → `ष` で `क्ष`。

| 操作 | 何が起きるか |
|---|---|
| **R2 を単独で叩く** | halant `्`（次の子音とくっつく） |
| L2 ＋ R2 | visarga `ः` |
| 右スティック ↑ | anusvara `ं` → もう一度で chandrabindu `ँ` → もう一度で外れる |
| 右スティック → | **長母音にする**（`क` → `का` / `कि` → `की`） |
| 右スティック ← | 1 字消す |
| 右スティック ↓ | 空白 → `।`（danda）→ `,` → `॥` |

★**R2 は「修飾の入口」**です。押している間に別の操作をすると halant にはなりません
（下）。

### 動かす・送る —— R2 と組み合わせる

★この席では**両スティックとも字に取られている**ので、カーソル移動と送信は
**R2 を押しながら**になります。

| 操作 | 何が起きるか |
|---|---|
| **R2 ＋ 左スティック ←→** | カーソルを動かす |
| **R2 ＋ 左スティック ↑↓** | 行を移る |
| **R2 ＋ 左スティック押し込み** | 送る（★L3 単独は上の「別の層」なので送信になりません） |

★**空白は右スティック ↓** です。ヒンディー語も分かち書きするので、これが無いと
ELIZA が語を切れません。★`।`（danda）は文の切れ目で、**打つと相手はそこまでを
読みます**（英語の `.` と同じ扱いになります）。

右下の箱には、いま選んでいる**組の頭の字**（प क च ट त …）が出ます。

## ビルド

```sh
cd native && sh make_font.sh && sh build.sh    # フォントと本体
sh portmaster/build-port.sh                     # zip を組む
```

`aarch64` の Debian 13（trixie・glibc 2.41）で焼いています。ArkOS / AmberELEC
（glibc 2.31）では動きません。

## 入れ方

`higgins.zip` を PortMaster の `autoinstall/` に置いて PortMaster を起動すると
展開されます。★**そのあと一度再起動する**とランチャの一覧に出ます（実測）。

## 実機へ送る（開発用）

```sh
sh portmaster/build-port.sh
SSHPASS=ark sshpass -e scp -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null \
  -r portmaster/higgins portmaster/Higgins.sh ark@<IP>:/roms2/ports/
```

- ★**手で展開すると `gamelist.xml` に登録されず Ports の一覧に出ない**
  （PortMaster 経由で入れるか、ランチャ側で一覧を更新する）
- ★**md5 で照合する。** `scp` は回線が不安定だと途中で止まる。止まったら
  `ssh '<remote> gzip -c <file>' > local` に切り替えると通ることがある
- ★**`conf/` を上書きしない** —— 変換の学習とユーザー辞書がそこにある
- 画面を持ち帰るには `SDL_VIDEODRIVER=offscreen` と `ZENMAI_SCRIPT` /
  `ZENMAI_STOP` / `ZENMAI_RAW`（実機の SDL に `dummy` は無い。`offscreen` を使う）
